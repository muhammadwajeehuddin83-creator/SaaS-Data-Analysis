# SaaS-Data-Analysis
Interactive Power BI Dashboard and Python Data Cleaning Project.
SaaS User Growth & Engagement Analysis

#Project Overview
In this project, I analyzed a SaaS platform's dataset to understand user conversion rates and industry-specific usage patterns. After performing data cleaning and preprocessing using Python, I developed an interactive Power BI dashboard to visualize key business metrics.

#Tools & Technologies
Python (Pandas): Used for efficient data cleaning and handling missing values.
Power BI: Used for creating interactive visuals, slicers, and trend analysis.
Kaggle Dataset: The primary source for raw user and subscription data.

#Key Insights
Total Accounts: 500 unique user profiles analyzed.
Conversion Rate: Achieved a high conversion rate of 89.2%.
Top Performing Industry: FinTech emerged as the leader with the highest overall usage.
Growth Peak: The year 2025 saw the most significant spike in new user registrations.

#Repository Structure
SaaS_Dashboard.pbix: The core Power BI project file.
Reports/: Contains the PDF export of the dashboard and the detailed Insight Report.
data_and_Scripts/: Contains the Python source code (main.py) and the raw dataset in the data/ folder.

#How to Run
Ensure you have Python installed, then install the required library:
pip install pandas
Navigate to the data_and_Scripts/ directory and execute the script:
python main.py
Open the .pbix file in Power BI Desktop to explore the interactive dashboard.
